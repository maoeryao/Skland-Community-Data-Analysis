# 森空岛《明日方舟》社区内容消费与互动分析

## 📌 项目背景与痛点
游戏社区在内容运营中常面临“盲目推荐”的问题，由于缺乏对不同内容类型消费效率的量化认知，导致流量分配无法最大化。本项目旨在通过对森空岛社区数据的采集与工程化分析，定位内容供需矛盾，为社区运营（如创作者激励、推荐算法权重）提供数据支持。

## 🔍 核心业务洞察
1. **发现“时间累积偏差”**：不同帖子的存活天数差异巨大（新帖 vs 老帖），直接对比“总互动量”会产生严重偏差。项目引入 `days_alive`，创新性地使用 **“日均互动量 (daily_engagement)”** 作为核心指标，剥离时间干扰。
2. **定位“供需错配”**：数据表明，**闲聊类**帖子占比高达 56%，但日均互动量极低；而**攻略类**帖子仅占 10%，日均互动量却高出近 9 倍。证明社区对硬核攻略的需求极度旺盛，但创作者供给严重不足。

## 💻 技术实现与工程优化
- **真实数据与工程模拟**：包含一份 100 条真实采集的社区样本数据。为了验证代码在生产环境下的鲁棒性，基于真实分布特征，使用 Python 生成了 **100 万条模拟数据** 进行压力测试。
- **解决 OOM（内存溢出）**：摒弃了传统的 `pd.read_csv()` 一次性加载，采用 **Pandas 分块读取 (Chunking)** 技术，确保百万级数据处理时内存占用平稳。
- **向量化运算**：在时间解析与指标计算中，使用 Pandas **向量化操作** 替代低效的 `apply` 循环，将百万级数据的计算耗时压缩至毫秒级。
- **SQL 性能优化**：将数据写入 SQLite，并建立 **B-Tree 索引**，利用复合 `GROUP BY` 与聚合函数，实现百万级数据下的秒级聚合查询。

## 📂 文件结构
- `sample_data.csv`：100 条真实社区采集样本（用于锚定真实业务基线）。
- `01_import_data.py`：数据生成、分块清洗、向量化特征计算与入库。
- `02_sql_analysis.py`：通过 SQL 进行多维聚合与业务结论输出。

## 🚀 如何运行
1. 安装依赖：`pip install pandas numpy`
2. 运行数据工程脚本生成数据库：`python 01_import_data.py`
3. 运行 SQL 分析脚本查看业务结论：`python 02_sql_analysis.py`
